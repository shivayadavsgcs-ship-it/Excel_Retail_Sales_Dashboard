# Retail Sales Dashboard

## Project Overview
An interactive retail sales dashboard built in Microsoft Excel to summarize sales performance and explore revenue trends.

## Dashboard Highlights
- Total revenue, units sold, average customer rating, and total orders
- Revenue by product, category, and region
- Monthly revenue trends
- Interactive filters for region and category

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers
- Dashboard formatting and data visualization

## Key Insights
- Electronics generated the highest revenue among the categories shown.
- The dashboard compares revenue across four regions and nine products.
- Monthly revenue varies over the year, with the highest value shown in January.
